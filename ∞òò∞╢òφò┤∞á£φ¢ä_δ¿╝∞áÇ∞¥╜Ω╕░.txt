광주버블여지도 · 프리미엄 3D V2 전체 사이트 (버블알바 CSS 경로 복구)

1. 압축을 전부 풉니다. ZIP 내부에서 HTML만 따로 실행하지 마세요.
2. 디자인만 간단히 확인하려면 bubble-alba/index.html을 크롬으로 열어도 됩니다.
   기존 /css·/js 정적 파일 경로를 페이지 기준 상대 경로로 바꿔서 로컬 CSS가 로딩됩니다.
3. 메뉴 이동, 지도, 가입/게시판 등 사이트 동작까지 확인하려면 START_LOCAL_SITE.bat을 실행합니다.
   브라우저가 열리면 상단 '버블알바' 메뉴를 클릭하세요.
4. localhost 서버에서 실제 계정 로그인이 가능한지 여부는 서버 연동 조건에 따라 다릅니다.
5. 이 파일은 전체 사이트 배포본 형태이나, 운영 중인 albam09.com에는 적용하지 않았습니다.

변경 사항:
- 기존 원본 디자인/업소 콘텐츠/CSS/JS 파일 코드는 변경하지 않음.
- 104개 HTML 페이지의 정적 CSS/JS/이미지 참조 경로를 파일 로컬에서도 적용되게 수정.
- 버블알바의 ./css/bubble-alba.css 등 원본 스타일을 보존.
- 프리미엄 V2 외곽 프레임 CSS 유지.
- 원본 SEO canonical, 지도 링크 등 경로는 유지.
- CSS, JS 파일 및 이미지 파일 포함 여부 확인; ZIP 무결성 확인.
