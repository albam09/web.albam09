## `netlify.toml` 역할과 실제 변경

`netlify.toml`은 Netlify 배포 시 **명령 실행 순서와 배포할 폴더**를 지정. 직접 Google 순위를 조정하거나 자동으로 업소 자료의 진위를 증명하지 않음.

V18의 명령 순서:

1. `node scripts/build-search-pages.mjs`: 인덱스/8개 지역/지도 정적 파일, 원문 소개·주소 카드·H1 설명 생성.
2. `node scripts/check-release.mjs`: URL·리디렉션·사이트맵 기본 검증.
3. `node scripts/build-site.mjs`: Supabase 공개 게시글·탐험기·알바 게시글 동적 정적화(배포 환경 네트워크 접속 필요).
4. `node scripts/apply-v18-metadata.mjs`: 모든 공개 HTML 메타 키워드 및 OG/Twitter 항목 최종 적용.
5. `node scripts/verify-v18.mjs`: 5개 수정 범위 회귀검사.
6. `node scripts/check-forum-structured-data.mjs`, `node scripts/check-seo.mjs --fix-sitemap`: 기사 스키마·SEO·사이트맵 확인.
7. `node scripts/package-public.mjs`: 사용자에게 공개할 `dist/` 생성. SQL과 관리 문서, 스크립트·원본 좌표 데이터는 웹 공개 대상에서 제외.
