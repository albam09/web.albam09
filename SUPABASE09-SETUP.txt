광주버블여지도09 — 기존 albam08 Supabase 공유 프로젝트 안전 설정

중요
- 새 Supabase 프로젝트를 만들지 않습니다. 기존 albam08 프로젝트를 그대로 사용합니다.
- auth.users / public.profiles / 기존 08 트리거·정책은 수정하지 않습니다.
- 실행 파일은 SUPABASE09.sql 하나입니다. (SUPABASE09_SAFE_FINAL.sql과 동일 내용)
- 예전 SUPABASE09-PHONE.sql / SUPABASE09-SUPERADMIN-PERMISSIONS.sql은 신규 설치에서는 실행하지 마세요.

1) 기존 08 Supabase > SQL Editor에서 SUPABASE09.sql 전체를 1회 실행

2) Authentication > Providers
   - Email 로그인 사용 시 Email을 Enabled
   - Google 로그인은 기존 08 Client ID / Client Secret을 그대로 사용

3) Authentication > URL Configuration > Redirect URLs에 추가
   https://albam09.com/auth/callback/
   기존 08 Redirect URL은 삭제하지 않습니다.

4) Google Provider 사용 시
   Authorized JavaScript origin: https://albam09.com
   Supabase callback URI: https://ldyysvafgegsgmvpslui.supabase.co/auth/v1/callback

5) Storage
   albam09-explore 버킷은 Public입니다.
   업로드/삭제 정책만 사용하며, 버킷 파일목록 전체를 공개하는 broad SELECT 정책은 만들지 않습니다.

주요 주소
/login/             회원가입·로그인
/messages/          쪽지함
/member/            내 정보
/admin/             관리자
/explore/           탐험기 메인
/explore/archive/   전체 공개 탐험기
/explore/write/     회원 전용 글쓰기

동작 원칙
- 08 회원/auth/profiles를 09에서도 공유합니다.
- 비회원도 published 탐험기를 읽을 수 있습니다.
- 일반회원 탐험기는 pending 후 관리자 승인 시 공개됩니다.
- 공개 탐험기 이미지는 공개 URL로 표시되며 업로드는 로그인 사용자 자기 폴더만 허용합니다.
- 쪽지는 로그인 회원만 접근합니다.
