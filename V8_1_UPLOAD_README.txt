ALBAM09 V8.1 — 모바일 메뉴 / 왼쪽 업소 슬라이드 / 탐험기 구조화 데이터
작업 완료일: 2026-11-09

이 ZIP은 기존 V8 전체 사이트에 이번 수정 사항을 반영한 파일입니다.
압축을 풀면 index.html이 바로 보이는 폴더를 Netlify에 업로드하세요.
현재 운영 사이트에 자동으로 배포한 것은 아닙니다.

1. 모바일 메뉴
- 6열 × 2줄을 유지했습니다.
- 이전 파일은 88/82px 메뉴 행 안에 60/62px 버튼이 들어가 두 줄 사이가
  37/29px까지 벌어졌습니다. 일부 버튼만 57/54px인 충돌도 있었습니다.
- 행, li, 실제 a 버튼 높이를 하나의 값으로 맞췄습니다.
- 두 줄 사이 간격은 9px입니다. 모든 메뉴 글꼴 크기도 화면별로 통일했습니다.
- 홈과 지역 페이지의 모바일 화면에서 실제 클릭 버튼을 측정했습니다.

2. 인덱스 지역별 업소 탐색
- 업소 카드가 왼쪽으로 움직이며 다음 업소가 오른쪽에서 들어옵니다.
- 평상시에도 다음 카드의 끝부분을 조금 보여줍니다.
- 기본 표시 시간 3.6초 + 이동 시간 0.65초입니다.
- 지역 안에서 순서를 섞고 바로 같은 업소가 반복되지 않게 했습니다.
- 마우스 올림, 키보드 포커스, 터치 중에는 자동 넘김을 멈춥니다.
- 일시정지/재생 및 다음 버튼, 왼쪽 쓸어넘기기를 지원합니다.
- 화면 밖의 카드와 숨겨진 탭은 자동 넘김을 멈춥니다.
- 동작 줄이기 설정에서는 자동 재생을 끄고 수동 이동을 즉시 처리합니다.
- 업소 이름과 링크가 카드와 함께 이동합니다. 이동 중 잘못된 탭은 차단합니다.

3. Search Console 탐험기 경고
- 제공된 화면의 마지막 수집일은 2026-10-20/22입니다.
- 2026-11-08 실제 공개된 두 문제 URL의 현재 HTML에는 author와 datePublished가
  이미 있었으며 중복 DiscussionForumPosting Microdata는 없었습니다.
- 따라서 구글 로그인 자체가 이번 경고의 원인이라고 볼 근거는 없습니다.
- 현재 빠진 author.url은 실제 작성자 공개 프로필 페이지를 생성해 보완했습니다.
- 프로필은 공개 닉네임과 공개 글만 표시합니다. 구글 이메일, 로그인 토큰을 넣지 않습니다.
- js/forum-schema.js 한 파일로 정적 빌드와 브라우저 생성 규칙을 통일했습니다.
- 실제 저장된 게시일/작성일만 사용하며 임의 날짜를 만들지 않습니다.
- 댓글 조회에 실패해도 본문 구조화 데이터를 먼저 생성합니다.
- 비공개/삭제 글과 필수 정보가 없는 데이터는 잘못된 공개 스키마를 내보내지 않습니다.
- 빌드 마지막에 scripts/check-forum-structured-data.mjs가 누락, 중복 노드,
  글 URL 불일치, 작성자 페이지 누락을 검사합니다.
- 현재 공개 탐험기 3개 및 작성자 페이지 2개를 ZIP에 포함했습니다.
- 새 공개 글은 기존 Netlify 빌드가 실행되면 정적 HTML과 작성자 페이지도 갱신됩니다.

배포 후 Search Console:
1) 오류 목록에 나온 /explore/post/.../ 주소에서 URL 검사 → 실제 URL 테스트.
2) 토론 포럼 보고서에서 수정 결과 확인 후 '수정 결과 확인'을 실행하세요.
3) author/datePublished/url을 포함한 최신 HTML을 구글이 다시 수집해야 보고서가 바뀝니다.
기존 수집 결과가 즉시 사라지거나 검색 순위가 올라간다고 보장하는 수정은 아닙니다.

4. 리디렉션
- /index.html → /, /page/karaoke1 → /page/karaoke1/ 등은 유지했습니다.
- 화면에 나온 9개 주소를 실제 확인했습니다. 모두 한 번의 301 뒤 정상 200 응답이고
  도착 페이지가 자기 주소를 canonical로 지정하고 있습니다.
- '리디렉션이 포함된 페이지'라는 상태만으로 도착 페이지의 색인 실패를 뜻하지 않습니다.
- /explore/post/* 와 /explore/author/* 의 200 규칙은 브라우저 주소를 바꾸는 301이
  아니라 정적 파일이 아직 없는 새 글/프로필을 위한 내부 템플릿 규칙입니다.

node scripts/check-release.mjs
node scripts/check-forum-structured-data.mjs
