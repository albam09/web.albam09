광주버블여지도 / 원본 사이트 + 외곽 3D 프레임
제작: 2026-11-01

본 ZIP은 실제 albam09 원본 사이트 전체 파일을 보존하면서, 화면 가장 바깥 테두리에만
얇은 입체 두께, 흰색 반사광, 핑크빛 레이어, 아래쪽 음영을 적용한 배포용 파일입니다.
원본 업소 데이터, 지도 스크립트, 링크, 로그인/회원기능 코드, 글꼴, 사진 크기 등은 변경하지 않았습니다.

적용 파일: css/bubble-outer-3d-20261101.css
HTML 내 태그: <link data-bubble-3d-frame=...>와 <div id=bubble-viewport-frame ...>
모바일에서도 화면 전체폭 유지. 고정 프레임은 pointer-events:none으로 클릭 방해 없음.

설치:
  - ZIP 압축 해제 후 START_LOCAL_SITE.bat 실행 (Windows)
  - 또는 ZIP 안의 파일 전체를 Netlify 사이트에 배포
  - 시작 페이지: index.html
  - 파일을 하나씩 개별 배포하지 말고 폴더 구조 전체 유지
  - 운영 사이트 배포 전 기존 사이트 백업 권장

주의: 이 빌드는 기존 코드에 시각적 프레임만 추가한 것이며,
실서버 로그인, 데이터베이스, 외부 지도 API의 실시간 연결 성공을 보증하지 않습니다.
