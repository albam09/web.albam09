# V15 지도 주소·길 안내 검토

2026-11-10 기준, V14를 바탕으로 작성했습니다. 운영 사이트를 직접 배포한 결과는 아닙니다.

- 지도 페이지 10곳에서 지역 버튼의 기존 순서를 유지하고 목포·남악을 맨 마지막에 두었습니다.
- 기존 지도 좌표가 있는 업소 54개의 50개 서로 다른 좌표를 지오코더의 역지오코딩으로 조회했습니다. 반환된 필지·건물 도형이 좌표를 포함하는지 검사하고, 도로명과 지번이 반환된 경우 둘 다 저장했습니다.
- 각 주소는 사이트 파일에 저장되어 목록과 정보창에 표시됩니다. 현재 54개에 대한 표시에는 카카오 키가 필요하지 않습니다. 키가 연결된 경우 새로운 위치는 기존 카카오 주소 조회를 사용할 수 있습니다.
- 주소는 지도 핀이 가리키는 장소의 주소입니다. 업소 자체의 주소로 단정하지 않고, 별도로 등록된 상세 주소가 있으면 보존해 같이 표시합니다. 지도 핀은 옮기지 않았습니다.
- 모든 업소에 `길 안내` 버튼이 있습니다. 좌표가 있으면 기존처럼 카카오 지도에 업소명과 정확히 같은 핀이 표시됩니다. 좌표가 없으면 등록된 상세 주소, 없으면 업소명과 지역의 검색 결과로 연결됩니다.
- 지도 위치 자료: 기미나인 지오코더 https://geocoder.gimi9.com/doc/ . 요청 좌표, 원본 응답 필지·건물 형상 및 기준월은 `data/build/pin-address-audit.json`, 화면용 결과는 `data/map-pin-addresses.json`에 있습니다.

## 현재 핀이 없는 업소

왕가구조선, 빠담빠담, 넘버원노래홀, 달콤노래방, 명품노래홀, 백프로노래홀, 보스, 빙고노래홀, K-1, 여대생은 V14에 좌표가 없었습니다. 이 중 빠담빠담·넘버원노래홀·달콤노래방·보스·빙고노래홀은 기존 상세 주소를 보존해 주소 검색으로 연결했습니다. 나머지는 지역과 상호 검색으로 연결합니다. 실제 위치를 확인하기 전 임의 좌표는 표시하지 않습니다.

## 위치가 일치하지 않는 예시

강아지노래홀의 현재 핀은 치평동 1162번지의 상무시민공원 쪽입니다. 또한 첨단아이의 기존 등록 주소는 첨단중앙로152번길 81-4이고 현재 핀의 위치 주소는 첨단중앙로152번길 6-15입니다. 이 위치들은 서로 다른 주소이므로, 실제 업소 위치와 기존 핀을 확인해야 합니다. 지도 지점 주소 변환만으로 해당 업소가 그곳에 있다는 사실을 확인할 수 없습니다.
