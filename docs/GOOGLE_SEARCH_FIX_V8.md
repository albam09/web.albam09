# V8 검색 구조·지역 정보 수정

버전: 20261108-search-fix-v8 / 2026-11-08 한국시간

- 업로드된 V7 전체 파일을 기준으로 수정했습니다. 기존 이미지·폰트·CSS는 바이트 단위로 보존했습니다.
- 업소 64곳을 보존하고 제공된 주소·위치 단서에 따라 19곳을 재분류했습니다. 상무지구 34, 광천동·서구권 3, 신안동·유동 15, 용봉동 3, 첨단 7, 목포·남악 2곳입니다.
- 19곳 재분류는 기존 파일의 주소·랜드마크에 근거합니다. 현장 영업·정확한 층수·요금이 새로 검증됐다는 뜻은 아닙니다.
- 북구 8곳과 화정동 왕가구조선 1곳은 제공 주소와 기존 핀의 지역이 충돌하여 지도 핀·거리 정렬에 쓰지 않게 했습니다. 목록·전화·사진·주소 검색은 유지하며 원래 좌표는 data/venue-directory.json의 previousCoordinates에 보존했습니다. 주소 또는 현장 위치를 확인한 뒤 좌표를 넣어 주세요.
- 메인은 지역 선택에 집중하고 karaoke 지역 페이지는 해당 지역 업소 비교를 담당하도록 제목·소개·본문을 구분했습니다. 메인에 전체 업소 상세 설명을 반복하던 부분을 정리했습니다.
- HTML·검색·지역 JSON/JS·지도·구조화 데이터·GEO 자료가 같은 업소 원본에서 생성됩니다. 수정할 원본은 data/venue-directory.json입니다. node scripts/build-search-pages.mjs 실행 시 관련 파일을 함께 갱신합니다.
- 위치가 불확실한 업소를 정확한 LocalBusiness 주소·좌표로 선언하던 구조를 공개 목록 ItemList로 정리했습니다.
- 지역 URL /page/karaoke1/ ~ /page/karaoke8/ 및 자기 canonical을 유지했습니다. index.html 별칭은 해당 지역으로 301 처리합니다.
- 클릭한 좌표를 역지오코딩해 사업장 주소처럼 덮어쓰던 처리를 제거했습니다.
- 전체 지도에서 지역 지도 복원, 재분류된 업소의 옛 지도 링크, 과거 탐험기의 업소 연결을 함께 수정했습니다.
