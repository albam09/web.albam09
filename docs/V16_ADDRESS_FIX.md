# V16 지도 목록 주소 표시

2026-11-10 실제 운영 사이트 점검에서 지도 HTML은 이전 데이터 형식인 반면 지도 스크립트는 V15인 상태를 확인했습니다. 이 조합에서는 개별 업소의 `pinAddress` 값이 없어 지도 목록이 동 이름만 출력됩니다. 운영 사이트에서 확인한 `site-version.json`은 `20261109-v14-reviewed`였습니다. 그 조합이 생긴 배포 경로는 확인되지 않았습니다.

지도 스크립트에도 기존 좌표 주소 자료를 함께 포함하여 이전 형식 HTML을 만나더라도 좌표가 일치하면 주소를 복원합니다. 전체 빌드는 데이터 원본, 스크립트의 복사본 및 각 지도 HTML을 함께 생성하며 세 부분을 검사합니다. 목록은 기존 등록 주소가 상세하게 있으면 층수를 보존해 그 주소를 표시하고, 그렇지 않으면 핀 위치의 도로명 또는 지번을 표시합니다. 예를 들어 심쿵노래홀은 `광주광역시 북구 중흥로 86, 2층`, 7seven은 기존 핀 기준 `전남광주통합특별시 서구 치평동 1211-1번지`입니다.

현재 64곳 중 59곳에 번지 또는 도로명 주소가 있습니다. 좌표와 상세 주소가 모두 없는 다섯 곳은 왕가구조선·명품노래홀·백프로노래홀·K-1·여대생입니다. 다섯 곳의 주소나 좌표는 임의로 만들어 넣지 않았습니다. 59곳 가운데 일부 주소는 사업장 위치로 검증된 것이 아니라 기존 지도 핀 위치를 변환한 주소입니다. 위치가 잘못되었다면 업소도 잘못 안내할 수 있으므로 실제 위치 확인이 필요합니다. 이전 V15 검토 문서에는 강아지노래홀과 첨단아이의 불일치 사례가 기록되어 있습니다.

모든 `길 안내` 버튼을 유지합니다. 기존 좌표가 있는 업소는 카카오맵에서 업소명과 해당 핀을 보여 주며, 좌표가 없으면 상세 주소나 상호 검색으로 연결합니다.

Netlify 수동 배포에는 `ALBAM09_V16_ADDRESS_DISPLAY_DEPLOY.zip`을 압축 해제한 폴더를 사용합니다. `index.html`, `map`, `js`가 폴더 바로 안에 있어야 합니다. 기존 사이트의 Deploys 화면에서 폴더 전체를 올립니다. 파일 일부만 올리면 새로운 파일과 예전 파일이 섞일 수 있습니다. 배포 후 `https://albam09.com/site-version.json`에서 `20261110-v16-list-addresses`를 확인하세요. 자동 빌드를 사용하는 경우에는 같은 버전의 전체 소스와 빌드 설정을 반영해야 합니다.
